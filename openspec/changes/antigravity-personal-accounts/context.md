# Context

Google's 2026-05-19 announcement ended consumer Gemini CLI/Code Assist support on 2026-06-18 and directs free/AI Pro/Ultra users to Antigravity. The official Antigravity Python SDK requires an API key and is not evidence that a personal subscription supplies an inference API. CLIProxyAPI's MIT-licensed Antigravity adapter is a concrete private-protocol reference: separate OAuth identity, loadCodeAssist project resolution, daily-cloudcode generation and fetchAvailableModels. Its headers and static model lists are not entitlement proof.

Preserve Python/FastAPI/SQLAlchemy, React, uv/Bun/Make and Docker. OAuth client configuration belongs in server environment rather than committing another installed-client secret. A callback landing on localhost:51121 is copied back into the web form; no external port80/router change is required. Only a fixed free-tier initialization attempt may be requested with operator consent, with Google deciding acceptance. Privacy/validation/project requirements must remain visible; paid tiers and credit-spending options must not be enabled implicitly.

Example: a Pro operator signs in with the subscribed Google account, discovers account-provided model IDs, selects one, creates a separate gateway client key and uses the explicit Antigravity Gemini base URL. A free operator follows the same path, with Google determining actual limits. A model catalog observation is not proof of inference access. Final acceptance requires successful ordinary/streaming generation and persisted tokens through an actual account, or a clearly recorded authorization blocker.

The two client-profile settings use the existing Settings resolver: deployment identity is T1, and the SecretStr T2 value seeds encrypted per-source credentials. Existing refresh uses the stored profile rather than environment overrides. The field budget increases from 96 to 98 because a separately registered client cannot default to a committed secret or reuse the enterprise client's identity. No application module reads process environment directly. The MIT reference notice is retained inside app/modules/gemini/ so the unchanged wheel and Docker source packaging include it.

Native CLI histories without custom session headers derive a stable first-user-content hash. Durable ownership remains scoped by key/provider; appended tool/signature turns retain their owner, while conflicting pins, other keys and disabled owners fail closed. Identical first content shares ownership; use a unique explicit session header for separate conversations and keep it across history compaction. Controls are preserved rather than silently stripping safety, output limits or tools. Paid-credit control fields are rejected, but JSON tool data containing the same property name is not mistaken for an opt-in.
